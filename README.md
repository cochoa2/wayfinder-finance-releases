Wayfinder Finance runs entirely on your own computer with no accounts, no cloud sync, and no bank logins. See the [download page](https://cochoa2.github.io/wayfinder-finance-releases/) for first-time macOS and Windows install instructions.

> **Not financial advice.** This is a planning tool built on public tax rules and market assumptions. Treat its numbers as informed estimates, and check big decisions with a qualified professional.
